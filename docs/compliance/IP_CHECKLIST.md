# IP and materials review checklist

All items remain open until the participant completes final review; creating provenance and disclosure drafts is not a license or rights determination.

- [ ] Every dataset has provenance
- [ ] Dataset license/access terms reviewed
- [ ] Third-party software disclosed
- [ ] Software licenses reviewed
- [ ] Literature figures not copied without permission
- [ ] Demo uses team-generated figures where possible
- [ ] Third-party images properly licensed
- [ ] Public repository excludes restricted material
- [ ] Kaggle Writeup contains no confidential information
- [ ] AI-assisted content independently verified
- [ ] Final claims match actual results

Working references: [data provenance](DATA_PROVENANCE.md), [third-party tools](THIRD_PARTY_TOOLS.md), [prior work](PRIOR_WORK_DISCLOSURE.md), and [figure manifest](../../submission/figures/FIGURE_MANIFEST.md).
