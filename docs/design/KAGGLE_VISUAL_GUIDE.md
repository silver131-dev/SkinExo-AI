# SkinExo-AI Kaggle visual guide — VISUAL-V1

This guide controls presentation only. The S2 narrative contract and claim dictionary remain the scientific source of truth.

## Hero

- Use a Pearl White canvas with a restrained Mist Mint to Powder Aqua membrane gradient.
- Keep **SkinExo-AI** and the canonical functional title dominant.
- Use the one-line pitch beneath the title.
- Include one abstract EV membrane motif at low opacity; human skin imagery is optional and secondary.
- Do not place a face, cosmetic jar, syringe, or treatment outcome in the hero.
- Recommended crop: 16:9 master with a center-safe 3:1 thumbnail zone.

## Thumbnail

Use the product name, a three-context motif, and a single response-component grid. At small size, retain only:

1. `SkinExo-AI`;
2. `Context-aware EV response`; and
3. three labeled context nodes.

Do not use detailed pathway text, similarity values, or a human face in the thumbnail.

## Section dividers

- Pearl White or Warm Ivory background.
- Small uppercase Deep Ink eyebrow.
- One 1 px Champagne rule or translucent membrane curve.
- Section title no longer than two lines.
- Use Soft Blush only for the scientific turn and Pale Lavender for phenotype/reliability transitions.

## Figure framing

- Preserve each scientific figure unchanged inside a Pearl White frame.
- Use 32–48 px equivalent outer margins.
- Add a Deep Ink figure number and short title above the image.
- Add source and limitation below the image in smaller Deep Ink text.
- Never recolor plot marks in a way that changes state or direction meaning.
- Never crop legends, null-state labels, axis names, or reliability notes.

## Caption pattern

Use three short parts:

> **Claim.** What the figure supports. **Method.** Which frozen artifact or metric it uses. **Boundary.** What it does not establish.

Example:

> **CTX003 retrieves CTX002 first.** R1 uses mask-aware NES cosine over shared-tested components. This is descriptive retrieval across three observed contexts, not predictive validation.

## Core visual sequence

1. Platform architecture — `fig09_skinexo_platform_architecture.png`
2. Three-context Response Atlas — `fig08_context_aware_response_atlas.png`
3. Interpretable context retrieval — `fig10_context_retrieval.png`
4. Similarity matrix, if space permits — `fig11_context_similarity_matrix.png`

The architecture and Atlas should appear before the retrieval figure so the similarity metric has an interpretable data model.

## Page-width checks

- Verify figure text at Kaggle’s rendered article width, not only full-screen.
- Use the original high-resolution PNG files; do not screenshot the Markdown page.
- Keep table columns narrow enough to avoid horizontal scrolling for the five P/M/E/A/I rows.
- State text, symbols, and borders must remain visible if color saturation is reduced.

## Prohibited treatments

- Paper-owned figures or licensed article screenshots
- Beauty advertising before/after imagery
- Efficacy language in visual callouts
- Neon gradients, glowing HUD rings, or animated code backgrounds
- Similarity labeled as accuracy, confidence, or prediction score
- A single green/red encoding without state text
