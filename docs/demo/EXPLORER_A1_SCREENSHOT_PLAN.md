## Capture guidance

- Use a desktop viewport wide enough to keep five axis cards on one row.
- Keep browser zoom and Streamlit theme consistent across captures.
- Do not crop away limitations, timepoint labels, or the “not predictive validation” language.
- Redact nothing from the UI because A1 intentionally exposes only trackable project metadata and public references.
- Automated browser capture was not required for A1 validation; perform final captures during the demo-video stage from the actual running application.
